# Huedoku — site

Site vitrine de l'app [Huedoku](https://github.com/paulgerold/huedoku), publié avec GitHub Pages.

- `index.html` : présentation du jeu
- `privacy.html` : politique de confidentialité (URL à renseigner dans App Store Connect et Google Play)

HTML et CSS statiques, sans build. Le français ou l'anglais est choisi selon la langue du navigateur (`?lang=fr` / `?lang=en` pour forcer). Les polices (Bricolage Grotesque, DM Sans, licence OFL) sont hébergées sur le site, sans appel à Google Fonts.

Aperçu local :

```bash
python3 -m http.server 8000
```
